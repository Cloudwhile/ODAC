# The architectures ODAC builds for, one per line:
#
#   <target> <subtarget> <arch>
#
# <target>/<subtarget> selects the OpenWrt SDK and the release download path,
# <arch> is the ABI architecture the produced APKs declare.
#
# This list is the single source of truth. The build matrix, the release
# completeness check and the workflow validation all read it, so they cannot
# drift apart. Two targets may share an <arch> (bcm27xx/bcm2710 and
# mediatek/filogic are both aarch64_cortex-a53); the file names of the
# produced APKs carry the target, so the artifacts do not collide.
#
# The Cudy TR3000 is mediatek/filogic.
